# 家长会与家校沟通（资源锚点 + 框架交付流程）

老师问「开家长会的资料/视频」「家校沟通」时走此参考。原则：先交框架待确认，不确认不出成品。

## 交付流程
1. **先出五部分框架草案**（见下），同时向老师确认四项：班级学段、会议时长、内容重点（学情通报为主 vs 方法指导为主）、产出形式（提纲/发言稿/PPT）。未确认不产出成品——方向错了整件返工。
2. 确认后按产出形式交付：发言稿直接文字代出；PPT 走流程 10（`flow-pptx.md`），学段/教材信息写进 subtitle 与讲稿备注。
3. 推荐了 ≥2 个知识库视频时顺手建学习清单（流程 2 第 5 步）。

## 家长会框架（五部分，全程不点名不施压）
1. **开场定调**：说明会议目标（交流学情、家校配合），明示不排名不点名防焦虑。
2. **学情通报四段式**：①定调防焦虑（整体平稳、进步是主流）→ ②表扬带氛围（讲课堂参与、作业习惯等整体亮点）→ ③可操作建议（给家长 2-3 件居家能落实的事，如固定作业时间、每天 10 分钟听读）→ ④预告课堂（下阶段安排 + 家长需配合什么）。
3. **家校分工**：老师课堂盯学；家长居家弹性督促，不当「第二老师」不加压；异常分级处理（请假类安抚为主，态度类私下沟通、尊重老师底线共识）。
4. **正向反馈闭环**：孩子有进步老师即时同步、家长当场表扬强化；家长验证有效的方法老师背书推广。
5. **答疑预案**：预设高频问题应答口径（怎么在家辅导／孩子不开口怎么办／作业量怎么看）。
