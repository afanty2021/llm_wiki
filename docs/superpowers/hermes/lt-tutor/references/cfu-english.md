## 1. 检测维度（aspect 等价物）

确认的语言成分落在哪个课标要素里，维度随之而定：

| 成分落在 | 维度 | 检测揭示什么 |
|---|---|---|
| 语法知识（形式—意义—使用） | **语法运用** | 能否在语境中选用正确形式表达意义，而非背规则 |
| 词汇知识 / 语音知识 | **词汇与拼读** | 音形义联结、词块搭配、构词法猜词 |
| 语篇知识 / 语言技能·理解性 | **语篇理解** | 获取梳理、推断隐含意义、辨析结构 |
| 语用知识 / 语言技能·表达性 | **语用得体** | 语境中得体表达与回应 |
| 跨两要素 → **混合**，注明哪题盖哪要素。维度写进教师指南信息头；它决定题型与好干扰项的样子。引用吻合的学业质量编号（如 2-6）作标准代码；页脚课标依据同 lp-standards-english.md。 |

## 2. 错误模式 → 题干特征映射（出题前必建）

Chinese EFL 学习者有记录的反复错误模式，主因 L1（汉语）迁移。每条问自己：*这样推理的学生在这道题里会做什么？题干必须含什么才能给他暴露的机会？*

| 错误模式 | 前置缺口 or 本级？ | 题干必备特征 |
|---|---|---|
| 时态标记遗漏：谈已发生的事仍用动词原形（汉语动词不变形表时间） | 本级（二级起） | 题干时间状语必须承载时间信息（yesterday / last weekend），不靠图片 |
| 三单 -s 遗漏 | 本级 | 主语必须明确为第三人称单数 |
| be/do 混用、疑问句不倒装（汉语语序直移：*Where you went?*） | 本级 | 用疑问句改写或选择任务触发 |
| 冠词 a/an 遗留或误用 | 前置 | 单数可数名词首次出现于语段 |
| 同根词词性误用（*happy* vs *happily*） | 本级（三级） | 空格所在句法位置决定所需词性 |
| 近义词/搭配误用（*do* a mistake；中文动词直移） | 本级 | 词块完整出现在语境中，不孤立考词条 |
| 字面理解代替推断：选文中原句而非推论 | 本级（三级） | 正确项必须是推论；原文原句须作为干扰项出现 |
| 过度推断：加入语篇没有的主观联想 | 本级 | 干扰项 = beyond-text 选项 |
| 指代理解错（it/they/one 回指错位） | 前置 | 语篇含至少一个跨句指代 |
| 语用直译：对赞美回 *No, no*，正式度错位 | 本级 | 语用题语境需标明关系与场合 |
| 拼读混淆（形近词 look/like；音近词 ship/sheep） | 前置（一级~二级） | 认读任务含形近/音近对照 |

此表是内部工作台，两卷均不出现。**先写题干后补的干扰项只会「错」不会「像」，区分不了任何东西。**

## 3. 出题（1–3 题）

宁要一道有区分度的题，不要三道没有的。题型随维度、限定在级别内：

| 级别 | 题型 |
|---|---|
| **一级（3~4）** | 听选图、认读匹配（词—图）、口头应答（教师问学生答，30–60 秒）、参照范例选句。任务指令可用中文，语言内容用英文 |
| **二级（5~6）** | 语境选词、句式转换（一般现在→过去）、读图写一句、简短对话应答选择。题干英文 |
| **三级（7~9）** | 语篇推断选择、语境语法填空（给提示词）、1–2 句书面产出（配评分要点） |

- **表象性（词汇与拼读维度）**：至少一题配对 音/义/形——图选择、读后匹配、或教师读词三选一。
- **语法运用**：至少一题让形式出现在**学生读或写的句子里**，不做规则回忆题（绝不出现无承载语境的「用所给词的适当形式填空」）。
- **语篇理解**：题目指名或呈现语篇，只打它的一个成分（推断/指代/结构），不考泛泛的「理解了吗」。
- **词汇量守界**：级别的带内出题——超带测的是词汇缺口而非目标成分；带下学生看图就能答。
- **区分度**：至少一题允许学生**因错误本身**到达一个「看似正确」的答案（如时态遗漏的答案在孤立看时语法上成立），或在正确作答中暴露部分理解。
- **每题揭示思维**：选择题每个干扰项对应映射表中一个点名错误；书面/口头产出题问 how——二级「为什么选这个词？」、三级「文中哪里给出线索？」
- **选择题干扰项规则**：每个干扰项对应映射表中一个具体错误；**至少一个反映前置缺口**（前级别/要素）、**至少一个反映本级混淆**——这样不同作答路由到不同下一步。正确项不靠格式、长度或具体性被认出。语法题须亲手变位/变形每一个候选形式：一个「错」的动词形式只有当它恰是该错误会产出的形式时才是干扰项（不只是不合语法）。

### 学生面语言守在级别带内

题干超带=一道题里藏了第二道题，学生会落进一个他并不有的错误的干扰项里。

- **词汇**：级别教的词保留（*yesterday*、*weekend* 属于二级题）；其余用级别已有的词——一级题干指令用中文（「听一听，选出你听到的单词」）；二级英文指令一题不超两个生词；三级用英语组织但回避超出约 1600 词表的核心词汇。标准原文是写给老师的——教师指南可逐字引用，题目用学生的语言说同一件事。
- **句子**：一句一事，行为者在前。一级英文 ≤6 词（或中文指令）；二级 ≤10 词且至多一个从句；三级 ≤15 词，长度来自语篇本身。语境用学生熟悉的（校园、家庭、周末），不熟悉的语境要先被理解才能答题。
- **题干与选项是学生面的**：无标注、符号或加粗指示正确项或点名错误模式。一次写干净；学生卷可以原样印发。

## 4. 教师指南（聊天文本交付）

每题（中文）：

1. **每个作答揭示什么**——选择题每选项一行、产出题列预期回应类型，描述**可观察行为**：学生圈了什么、说了什么、写了什么。「选了动词原形（说明时态标记未建立）」可用；「不懂过去时」不可用。
2. **下一步**。点明类型——**前置缺口**（前一级别内容未牢固：路由到点名的前级别/要素，如「回到一级的一般现在时三单形式，先做口头替换操练」）或**本级混淆**（本课内容自身难点）——然后给具体动作：具体子技能、支架或任务型。前置缺口行必须路由到**点名的前级别或内容要求要素**，绝不「复习旧知识」。
3. **跨作答看什么**——两三句话：共同模式是否指向一个可整班路由的前置缺口，还是分散的本级混淆各需不同处理。**两行路由相同=数据没在工作。**

结尾三桶判读（已掌握 / 基本掌握需巩固 / 需再教）——CFU 用来读出信息，不打分；当堂完成、不留课后（双减）。

**指南信息头**（替代原 meta block，聊天开头紧凑给出）：标准锚（级别+内容要求要素句/学业质量描述逐字+编号）；年级·级别（如「五年级 · 二级」）；检测维度；学习目标两句话（掌握了这个的学生能做什么+在本卷如何显现）；前置要素 1–2 条（编号+要义，即前置缺口路由目标）；后续要素 1–2 条。

## 5. 两卷交付纪律（data-use guardrail + 一致性）

- **学生卷**（worksheet 出图）：只有题干+选项/作答区+姓名日期行。无信息头、无正确答案标记、无来源标注、无 next-step 语言。
- **教师指南**（聊天文本）：含上述一切，但**同样零来源标注**——无来源栏、无「检索到/未检索到」叙述、不点名教材版本、不留「按老师要求」「已经确认」类对话痕迹。检索到的错误知识内化为每行路由，文件不再叙述它。
- **题面跨卷逐字一致**——同题干、同选项、同顺序；一次写就，两处复用。这是学生卷可原样印发的前提。
- **口头应答型（一级常见）不出图**：听做/口头应答无纸面——题面+判读全在教师指南聊天里呈现，向老师说明口头施测。
- 学生卷 worksheet 版式：标题直接用主题名；首卡姓名日期 fill 行（「姓名：____ 日期：____」）；每题一卡或两题一卡（题干 text + 选项 checklist / 作答 fill）；每卡 2–3 块为宜，过密会被拒——拒了按老师意见精简或减题，**不牺牲题面一致性**。
- 版权：写原创题；绝不逐字复现教材语篇或成题；两卷不出现教材版本名。
