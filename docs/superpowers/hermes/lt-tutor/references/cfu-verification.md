两道门跑在每道题上；一道不过即修即重写，修完的版本才是老师看到的第一个版本。整个验证过程内部进行——不叙述、不外显「我检查发现…」。

读到这里时你应该已写完两卷。此时你心里有数哪是正确答案——一道带键的题有两个「正确答案」时你会觉得它没问题。所以两道门**按已写下的文本**逐题回读执行，并要求你**写下推理**（内部草稿，不进交付物）：打出来的辩护才是真做出来的辩护。

---

## Gate A —— 恰一个可辩护答案

每道选择题，逐个选项（含干扰项）写一行**「该选项正确的最强论证」**——只用题干本身陈述的信息。「错在它不是答案」是这门静默失败。然后数论证站得住的选项数：

- **恰一个** → 过。
- **两个及以上** → 按原样不可答，通常因为答案依赖一个题干从未点名的属性。修复顺序：(1) **题干点名该属性**，保留干扰项；(2) **删掉该选项**。
- **零个** → 题干信息缺失或键本身错了，重做该题。

四类「第二可辩护答案」高发源，直接查：

1. **约定非事实**——语法上等价的形式（*a×b* 与 *b×a* 一类在英语题里的对应：如语序可换的同义句、大小写或缩写变体 *don't* / *do not*）两个都在选项里就是两个正确答案，除非题干点名要哪种。
2. **等价形式多帽**——*1/2、0.5、2/4、50%* 式一件多穿；*Yes, I do.* 与 *Sure.* 式多个都对题干的合法回应。
3. **陈述句选项结论对但理由各异**——选项是完整陈述句（「对/错，因为…」）时，多个选项可携正确结论仅理由不同；此题式仅当题干明判理由时成立。
4. **约度、单位、未定精度**——数量/程度类选项（many/few、often/sometimes）在无参照基准时可各自辩护，除非题干定基准。

---

## Gate B —— 每个干扰项是真实学生推理的落点

Gate A 的反面：每个干扰项要揭示的那个错误，真的会把学生推到这个选项上吗？没有可描述推理到达的干扰项不会被选，为它写的那行判读永远等不来人。

**先把题干按写下的样子过一遍**——不是你想写的样子：时间状语到底给了没有、主语到底是不是三单、语篇里到底有没有那个指代。题干通常带上了你选它时想要的一个属性和没注意到的一个。

**然后对判读指南的每一行**，把该行点名的错误应用到题干实况上，说出它产出哪个选项：

- **恰好是该行自己的选项** → 过。
- **落到别的选项** → 不过。要么选项对该错误是错的，要么该行的断言是错的——修错的那边，再查它实际落到的行。
- **该错误套不进这道题干** → 此干扰项不可达。换成这道题干能产出的。

语法题的 Gate B 含**亲手变位/变形每一个候选形式**：时态题里每个候选动词形式都要实际变位过——一个干扰项只有当它恰是该错误产出的那个形式时才成立（*goes* 对三单遗漏的学生不可达，*go* 才是）。

产出题（无干扰项）的 Gate B 施于指南点名的每种预期回应：每种都是学生在此题干上真产得出的。

---

## 两门之后

修两门查出的，重写两卷，**对改动过的内容重跑两门**——修过的题干可能弄坏之前没问题的干扰项。仍不过的题**整题替换，不再打补丁**。
