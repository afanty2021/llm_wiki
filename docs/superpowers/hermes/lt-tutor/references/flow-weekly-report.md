# 流程 5：周报生成（cron 系统回合）

> **本文件是 teacher-tutor 技能的外移流程（原 §7）**——核心文件被压缩剪枝后按此重读。
> **触发**：仅 cron 系统回合（尾块 `identity_source:"system"`）；教师交互回合不得进入本流程。
> **身份**：本流程每次工具调用**必须显式带目标教师 `wecom_userid`**——取值只来自系统 prompt，缺失即停止调用并如实说明（核心 §0-4）。
> **输出**：整单链接独占一行、原样转发、一字不差（核心 §1 链接硬规则）。
> 核心节映射：清单生成手法=主文件 §5；主文件不在上下文时先 `skill_view("teacher-tutor")` 重载再对照。

**触发**：定时周报任务（系统模式）。prompt 给出目标教师 `wecom_userid`——**本流程每次工具调用都必须显式带它**（核心 §0 第 1 条只适用交互回合）。产出由系统送达教师本人。

1. `teacher_tutor_profile_get`（带 userid）：未建档（404）→ 只输出"该教师尚未完成入门问卷，本期暂无周报"即止。
2. `teacher_tutor_progress`：取近 7 天 ask 主题（`recent_events` 的 `question`）与各计划完成度——**已完成/已看过的方向降权**，不重复推刚学过的。
3. `teacher_tutor_plan_list`（`status:"active"`）：取进行中的学习任务与条目完成计数，供周报「学习任务」段（第 7 步）。
4. `llm_wiki_search` 2-3 个不同措辞查询取候选（`limit` 建议 5，比较后择优——即答疑流程的检索手法）。
5. `teacher_tutor_plan_create`：`origin` 固定 `"weekly"`；**不传 `period_key`**（服务端自算当周幂等，**禁止自行推算 ISO 周串**）；若 400 且 message 含 `expected_period_key=<周串>`，用该周串原样重试一次。`items` 3-5 项，**视频优先硬规则**：以 `media` 视频项为主体（视频 ≥2 且占多数），`wiki_page` 至多 1 项仅作延伸阅读，严禁概念页/文稿页凑数；视频不够宁少勿凑并说明。
6. **幂等**：同周已存在时 `plan_create` 原样返回既有计划——话术改口"本周清单已生成，链接如下"，附 `link`，**不要描述成新建**。
7. 输出中文周报短文：本周小结（来自 progress）→ **学习任务段**：已完成的列出条目、未完成的列出待学名单（数据来自第 3 步）；无 active 计划则一句话说明（如"本期暂无进行中的学习任务"）→ 新清单介绍（各项标题+一句话理由）→ **整单链接独占一行原样转发**（§1 链接硬规则）。
