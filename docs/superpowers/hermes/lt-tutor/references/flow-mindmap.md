# 流程 7：思维导图生成（检索 → 构造大纲 → 出图）

> **本文件是 teacher-tutor 技能的外移流程（原 §9）**——核心文件被压缩剪枝后按此重读。
> **触发**：老师要求生成思维导图/知识结构图（"画个思维导图""整理成导图"）。
> **身份**：交互回合工具调用不传 `wecom_userid`（系统锁定真实发送者，核心 §0-1）。
> **输出**：`MEDIA:<路径>` 行原样独占一行、一字不改；**多张时每张一行全部保留**（核心 §1 MEDIA 硬规则）。
> 核心节映射：身份规则=主文件 §0、输出硬规则（MEDIA/链接）=主文件 §1、工具白名单=主文件 §2；主文件不在上下文时先 `skill_view("teacher-tutor")` 重载再对照。

**触发**：老师要求生成思维导图/知识结构图（"画个思维导图""整理成导图"）。

1. **取材**：先 `llm_wiki_search` + `llm_wiki_read_file` 读库内真实课文——导图内容必须来自真实材料，**不编造课文外内容**。检索无果 → 如实告知该主题暂缺材料、先不出图（不编造）；老师坚持要 → 按其口述整理**文字版**大纲并注明非库内材料。
2. **构造大纲**：从材料提炼层级结构，调 `teacher_tutor_mindmap`：`title`（中心主题，≤60 字符）、`root.children`（分支树，每节点 `{label, children?}`，标签 ≤40 字符，整图 ≤5 层 ≤60 节点）。超限会被拒——按章节**拆成多张**，或与老师确认精简；**多张时每张的 `MEDIA:` 行都要原样保留**（一张一行，核心 §1）。
3. **MEDIA 回显（核心 §1 硬规则）**：一句话说明（主题、几层）+ 换行 + `MEDIA:` 行原样独占一行。
4. **失败回退**：工具返回失败文案 → 改发**文字版大纲**（层级缩进列表），说明图片稍后可再生成；**绝不给老师发 mermaid/graphviz 源码**（企微不渲染，就是乱码）。
