# 流程 10：课件 PPT 生成（取材 → 出片）

> **本文件是 teacher-tutor 技能的外移流程**——核心文件被压缩剪枝后按此重读。
> **触发**：老师要求做课件/出 PPT/幻灯片（"做个课件""把它做成 PPT""把这个视频做成课件""上课用的幻灯片"）。
> **身份**：交互回合工具调用不传 `wecom_userid`（系统锁定真实发送者，核心 §0-1）。
> **输出**：`MEDIA:<路径>` 行原样独占一行、一字不改（核心 §1 MEDIA 硬规则；仅 pptx 工具有 MEDIA 行——media_extract 无）。
> **构造手法**：pptx `slides` JSON 构造规则见本文件第 3 步；素材提取见第 2 步。
> 核心节映射：身份规则=主文件 §0、输出硬规则（MEDIA/链接）=主文件 §1、工具白名单=主文件 §2；主文件不在上下文时先 `skill_view("teacher-tutor")` 重载再对照。

**取材分四路**（按老师请求里的素材形态对号入座）：

1. **库内材料**（老师点名某课文/主题/视频名）：`llm_wiki_search` + `llm_wiki_read_file` 读库内真实材料（视频页按 `[mm:ss]` 锚点定位段落）——不编造材料外内容。
2. **老师发来视频/音频**（消息带系统注记行 `[video '…' saved at: 路径]` / `[audio …]`）：先 `teacher_tutor_media_extract`（`media_path` = 注记行里的完整路径，**勿自行拼凑**）——返回帧缩略图路径 + 带时间戳的转写文本 + mp3 路径；**帧缩略图用 `vision_analyze` 读取**了解画面内容（整张读即可，含 9 格画面）。话术：**「素材处理约 1-2 分钟请稍候；期间补发消息不会打断处理，但建议素材发齐后再开始」**。约束：≤15 分钟（超长 → 礼貌引导老师截取片段，或将素材入库后从库内取材）；>20MB 大文件企微可能拒收（引导走文件形式发送或入库）。
3. **老师发来图片**：`vision_analyze` 转写图片内容（整页密集图先 region 分块），以转写内容为材；图片本身可作课件配图页（路径取注记行）。
4. **老师口述/粘贴文本**：直接以文本为材整理结构（注明为老师提供的内容）。

检索无果/素材不可用 → 如实告知（口述内容可整理文字版大纲并注明非库内材料）。

**构造与出片**（`teacher_tutor_pptx`）：

2. `title`（≤40 字符，**直接用主题名如「一般过去时 The Past Simple Tense」，不带「课件/PPT」等文档类型字样**）、`subtitle`（可选）、`slides` 3-10 页（典型 5-8 页；每页 `heading` + `bullets` 2-5 条 + 可选 `note` 讲稿备注；封面页工具自动生成不算配额）。**页间结构服务教学**：导入页→要点页→操练/讨论页→小结页；勿把全部材料塞进少数页（每页要点 ≤6 条、每条 ≤80 字，过密会被拒——届时按老师确认精简或拆成两份）。
3. **嵌入素材（可选，v2）**：`slides[].image` = 整幅配图路径（该页为「标题+整幅图」版式，配图页 ≤4 页、单图 ≤5MB）——常用老师发的教材照片或视频帧画面截图；`audio_path` = 封面音频（≤6MB mp3，通常取 media_extract 返回的 mp3 路径；下载后点封面喇叭播放）。不需要嵌入就不传，纯文字课件同样完整。
4. **MEDIA 回显**（核心 §1 硬规则）。话术预告：课件是 .pptx 文件消息，点击下载后用 Office/WPS 打开编辑；含封面音频时点封面喇叭图标播放。
5. **失败回退**：**环境性失败勿反复重试刷屏**——改发文字版课件大纲（逐页标题+要点），说明课件文件稍后可再生成。素材缓存 24 小时清理，隔天重做=请老师重发素材（已生成的课件文件不受影响）。
