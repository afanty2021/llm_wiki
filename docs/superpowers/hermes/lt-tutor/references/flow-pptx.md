# 流程 10：课件 PPT 生成（检索 → 构造结构 → 出片）

> **本文件是 teacher-tutor 技能的外移流程**——核心文件被压缩剪枝后按此重读。
> **触发**：老师要求做课件/出 PPT/幻灯片（"做个课件""把它做成 PPT""上课用的幻灯片"）。
> **身份**：交互回合工具调用不传 `wecom_userid`（系统锁定真实发送者，核心 §0-1）。
> **输出**：`MEDIA:<路径>` 行原样独占一行、一字不改（核心 §1 MEDIA 硬规则）。
> **构造手法**：`slides` JSON 的构造规则在本文件第 2 步。
> 核心节映射：身份规则=主文件 §0、输出硬规则（MEDIA/链接）=主文件 §1、工具白名单=主文件 §2；主文件不在上下文时先 `skill_view("teacher-tutor")` 重载再对照。

**触发**：老师要求把某主题/课文做成课堂用的课件（16:9 可编辑 .pptx，含讲稿备注栏）。

1. **取材**：先 `llm_wiki_search` + `llm_wiki_read_file` 读库内真实材料（教材课文、视频转写页——视频页按 `[mm:ss]` 锚点定位段落）——内容必须来自真实材料，**不编造材料外内容**；检索无果 → 如实告知暂缺材料、先不出（老师口述内容可整理**文字版大纲**并注明非库内材料）。**边界（v1 钉死）**：老师发来视频/音频文件要求直接转课件、或要求 PPT 内嵌音频 → 礼貌说明暂不支持，可先出文字版课件大纲；素材已在库内的视频走转写页取材即可出课件。
2. **构造结构**：调 `teacher_tutor_pptx`：`title`（≤40 字符，**直接用主题名如「一般过去时 The Past Simple Tense」，不带「课件/PPT」等文档类型字样**）、`subtitle`（可选，如适用学段/单元）、`slides` 3-10 页（典型 5-8 页即可；每页 `heading` + `bullets` 2-5 条为宜 + 可选 `note` 讲稿备注——进演讲者备注栏不打上幻灯片；封面页工具自动生成不算配额）。**页间结构服务教学**：导入页→要点页→操练/讨论页→小结页的常见走向，勿把全部材料塞进少数页（每页要点 ≤6 条、每条 ≤80 字，过密会被拒——届时按老师确认精简或拆成两份）。
3. **MEDIA 回显（核心 §1 硬规则）**。话术预告：课件是 .pptx 文件消息，点击下载后可用 Office/WPS 打开编辑。
4. **失败回退**：**环境性失败勿反复重试刷屏**——改发文字版课件大纲（逐页标题+要点），说明课件文件稍后可再生成。
