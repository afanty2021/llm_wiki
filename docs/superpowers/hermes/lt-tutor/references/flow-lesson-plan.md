# 流程 11：教案生成（课标锚定 → 教研增强 → 分段交付）

> **本文件是 teacher-tutor 技能的外移流程**——核心快速路径表命中即按此执行。
> **触发**：老师要求设计课/出教案/教学设计/单元整体教学设计（含隐式：「明天要教 XX 怎么上」「帮我备这节课」）。
> **身份**：交互回合工具调用不传 `wecom_userid`（系统锁定真实发送者，核心 §0-1）。
> **输出**：教案分段文本消息 +（如出学生页）`MEDIA:<路径>` 行原样独占一行、一字不改（核心 §1）。
> 核心节映射：身份规则=主文件 §0、输出硬规则=主文件 §1、工具白名单=主文件 §2、引用规范=主文件 §4/§13；主文件不在上下文时先 `skill_view("teacher-tutor")` 重载再对照。
> **边界**：出学案/练习纸/操练卷→流程 8；做课件→流程 10；单独要当堂检测→流程 12（本流程自带 1 题当堂检测）；改写已有教案为分层版→如实说明暂不支持，可按本流程重新设计。

1. **预读（动工前置，跳过=关键失败）**：① `skill_view("teacher-tutor", file_path="references/lp-standards-english.md")` 全读——课标锚、级别分支、节结构、学情预设知识全在其中；② `teacher_tutor_profile_get` 取学段（幼儿/小学/初中）预填级别范围。
2. **澄清 + 草稿提议（一轮发完）**：按 lp-standards §1 的优先级问——最多 2 问（①年级（缺失时）②主题/话题或语篇（缺失时）；单元整体教学必问教材版本与单元）；其余静默默认。同一条消息带**草稿提议**：「我可以直接出完整教案，也可以先给你一个草稿速览，你看看方向再出全文——要哪种？」（完整为默认；老师明确要草稿才走第 4 步草稿路径）。
3. **课标定位 + 教研增强**：
   - **课标锚**（lp-standards §2）：级别判定 → 主题定位（T1）→ 内容要求要素（T3）→ 学业质量编号（T4，逐字引用仅一处）→ 前置知识一行。
   - **wiki 增强**：`llm_wiki_search` 1–2 轮不同措辞（如「英语学习活动观+主题词」「教材名+单元」「语篇类型+教学设计」；教材缩写按核心 §2 展开规则），命中 → `llm_wiki_read_file` 取设计参考；引用规范同核心 §4（来源+片段时间戳）。**幼儿段老师**：课标不覆盖 → 底座改为 ECE/LOE/Foundations 类语料检索（loe/ece 展开见核心 §2），教案开头明示依据，不套课标锚。
   - **无果降级**：照常产出，教案尾注「未引用库内材料，按通用教学法设计」；**不编造来源**（核心 §15）。
   - 顺带 `teacher_tutor_record_ask`（payload.question=老师的请求原话）。
4. **设计构建**：lp-standards §3——语篇研读三问（What/Why/How）为起点，目标从研读中来；活动观三层活动链；教—学—评一体化（每主活动配评价点）；按级别分支套活动弧 + non-negotiables；单元整体教学按 5 步结构。**版权红线**：教材语篇绝不逐字复现——引用只写「版本+年级+单元+语篇标题」+页码/板块指示，平行原创文本替代并告知老师；不假造教材板块名；原创语篇章在级别词汇语法带内。
5. **草稿路径**（仅老师选了草稿）：聊天速览——课标锚一行（编号+≤10 词要义）/ ≤3 句概要 / 环节 bullet（名+分钟+一句话）/ 学生任务速览 / 前提知识 / 当堂检测；草稿借用的名字与终稿一致（环节、任务叫什么将来就叫什么）。老师在草稿层提改动 → 改后重呈现；老师说「可以/出全文」→ 进第 6 步。
6. **交付**：教案正文按 lp-standards §4 的 8 节分 2–4 条消息交付（①②③ 一条、④⑤ 一条、⑥⑦⑧ 一条，教学过程超长可独占）；**一致性硬规则**：当堂检测题、句型支架、核心词汇、语篇原文在教案与学生页（及草稿）重复出现处**逐字一致**。学生页：二级/三级非纯听说课 → `teacher_tutor_worksheet` 出图（映射见 lp-standards §7），`MEDIA:` 行回显；预备级/一级听说课 → 明说无学生页（学生用图卡/TPR 回应）。worksheet 环境性失败 → 勿反复重试刷屏，如实说明并改发文字版学生任务。
7. **收尾问询 + 顺手建单**：问是否要调整 + 2–3 个**具体**迭代选项（如「给输出环节加句型支架 / 换成你教材的单元语篇 / 调低任务难度」），不说「有问题随时找我」。本次引用了 ≥2 个可学资源（视频/页面）→ 按核心 §4-5 顺手 `teacher_tutor_plan_create` 建小清单并附链接。
8. **修订**：改动**先改基线**（当堂检测题/核心词汇/句型支架/语篇），再同步全部重复出现处；改完做一致性清扫——任何一节不得残留被替换的旧语境、旧数字、旧任务表述。
