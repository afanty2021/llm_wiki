# 流程 12：当堂检测 CFU（焦点确认 → 出题 → 双验证门 → 交付）

> **本文件是 teacher-tutor 技能的外移流程**——核心快速路径表命中即按此执行。
> **触发**：老师要求当堂检测/课堂检测/出道题看看掌握没/小测一下（含隐式：「讲完了想看看谁会了」）。
> **身份**：交互回合工具调用不传 `wecom_userid`（系统锁定真实发送者，核心 §0-1）。
> **输出**：学生卷 `MEDIA:<路径>` 行原样独占一行、一字不改（核心 §1）+ 教师指南聊天文本。
> 核心节映射：身份规则=主文件 §0、输出硬规则=主文件 §1、工具白名单=主文件 §2；主文件不在上下文时先 `skill_view("teacher-tutor")` 重载再对照。
> **边界**：练习纸/操练卷→流程 8；单元测/期中期末卷不是 CFU——如实说明只做 1–3 题形成性检测（读出信息用，不打分），可建议逐知识点分次做；教案自带的当堂检测在流程 11 内，不进本流程。

1. **预读（动工前置，跳过=关键失败）**：`skill_view("teacher-tutor", file_path="references/cfu-english.md")` 全读——检测维度、错误模式映射、出题规则、两卷交付纪律全在其中。课标级别/主题/学业质量编号共用 `references/lp-standards-english.md` §1–§2（可按需再读，不必整读）。
2. **澄清（最多 1 问）**：年级未说明且不可推断时问（「五年级」和「初一」的级别、题面带内词汇、题型全不同）；主题能映射到两个语言点时问哪个。其余静默默认。顺带 `teacher_tutor_record_ask`（payload.question=老师的请求原话）。
3. **焦点确认（硬门——必须停下等老师回复）**：一个语言点含多个可分离成分，框定一个才有可行动的信号。① 从老师的语言点里审出候选成分（如「第三人称单数」→ 陈述句三单 -s / 疑问句倒装 / be/do 混用）；② 选**最可测**的一个——学生理解的真实分叉点，1–3 题探得出来；③ 用老师的话（非术语）一句话说它要求学生做什么+一行为什么+一个直接问题，**发出后停**——老师未回答不进第 4 步；老师改选（换成分或要多个）→ 其选择为锚，重述确认一句话。
4. **构建**：cfu-english §1 定维度 → §2 建错误模式映射（内部工作台，两卷不出现）→ §3 出 1–3 题（级别题型表、词汇带界、干扰项=一个前置缺口+一个本级混淆、语法题亲手变位每个候选形式）→ §4 成文教师指南（信息头+逐题逐选项判读+三桶路由）。
5. **渲染**：口头应答型（一级听做/口头应答）→ **不调 worksheet**，题面并入教师指南；纸面型 → `teacher_tutor_worksheet` 出学生卷（cfu-english §5 版式纪律：首卡姓名日期行、每题一卡或两题一卡、题面与教师指南逐字一致）。**此步结束时最终回复尚未发出**——交付被第 6 步闸住。
6. **双验证门（Step 6 前禁读 cfu-verification——此刻才读）**：`skill_view("teacher-tutor", file_path="references/cfu-verification.md")` 全读，对**已写下的卷面文本**逐题跑 Gate A（逐选项写最强辩护，恰一个可辩护）与 Gate B（逐行判读套用其点名错误，落在自己的选项上；语法题每个候选形式变位核过）。有不过 → 修（改过的重跑两门；仍不过整题替换）→ 学生卷有变 → 重调 `teacher_tutor_worksheet` 重渲染。**未过门不交付。**
7. **终发 + 收尾**：一条（或多条）消息：教师指南聊天文本（信息头→逐题判读→跨作答看什么→三桶）+ `MEDIA:` 行（核心 §1，口头应答型无）。收尾问是否合用 + **至多 2 个具体**调整项（「换个难度层 / 同一焦点再加一题 / 改成写一句的书面题」），不说「有问题随时找我」。老师选了调整 → 改后重过第 6 步再交付。
