# 学案设计参考（worksheet-lesson-notes.md）

> 出学案前的设计参考，来源：Green School 样例海报（标杆样例 distill）。
> 出图入口：`teacher_tutor_worksheet`；内容一律取自库内真实课文（search/read_file）。

## 一、版式结构（nature 主题自动套用，无需指定样式）

- **2×2 四卡**最经典：每张卡 = 一个教学环节（认识主题 → 信息表格 → 操练 → 应用），2-3 卡也可。
- 大标题 = **主题名本身**（如「一般过去时 The Past Simple Tense」），**不带「学案」「练习纸」等文档类型字样**（页面本身已经是学案，不用再自报家门）；副标题（课型/单元）+ 页脚（提交要求，如「完成后写在练习本上交给老师」）。

## 二、教学设计五模式（样例的核心套路）

1. **输入→产出配对**：每卡先给一句示范（语言输入），紧跟同句型的填空（产出）。
   例：示范 "Our classrooms look like this:" → 填空 "They are very unique because ___"。
2. **句型替换操练**：同一句型连做 3 遍换关键词，每行配 icon 提示答案类别。
   例：`{type:"numbered", items:[{before:"We grow"}]×3}`，卡 icon 用 🌻，学生看图填 flower/rice/banana。
3. **表格装真实信息**：课表、对照表用 `table`（≤5 列×4 行），挖空格留白让学生补。
4. **低门槛勾选穿插**：Yes/No 判断、动作勾选（Feed/Pet/Clean）——`checklist`，选项 1-2 词。
5. **开放产出收尾**：画画/自由表达框 v1 未有，变通=用 `numbered` 空行或 `text` 写指令。

## 三、块型速查（与工具 schema 一一对应）

| 想做什么 | 块型 | 注意 |
|---|---|---|
| 示范句/指令/知识点 | `text`（≤120 字符） | 一句一块，别堆段落 |
| 句中挖空 | `fill`（before+after） | 挖关键词留句型骨架；≤4 行 |
| 独立答题空线 | `numbered`（只有 before） | 自动编号+空线；≤4 行；**不带 after** |
| 选择/判断类 | `checklist`（≤6 项） | 选项宜 1-2 词 |
| 课表/分类表 | `table`（≤5 列×4 行） | 行列数必须一致 |
| 答案类别提示 | 卡片 `icon`（1 个 emoji） | 提示方向，不剧透答案 |

## 四、caps 对齐（超限会被拒，届时拆成两张）

2-4 卡、每卡 1-4 块、总文本 ≤1200 字符、预估版面 ≤1000px。**每卡 2-3 块、checklist 选项 ≤10 字最稳。**

## 五、内容纪律

- 全部句子取自库内真实课文（search/read_file），挖空挖实词、留功能词；
- 指令语用老师对学生口吻；中英混排时英文为主、中文作说明；
- 一张学案聚焦一个语言点（一个时态/一类词汇/一个功能句型）。
